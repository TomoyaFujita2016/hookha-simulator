# シーシャ熱・香りシミュレーター

ボウルと HMD の 3D 形状、炭の配置、吸う強さから、葉の上・中・下層の温度と、温度ごとに気化する香料・グリセリンを計算する静的サイトです。ビルド不要で、GitHub Pages（main ブランチのルート）でそのまま動きます。

## 使い方

- 条件（ボウル、HMD、炭の配置、炭のサイズ、フレーバー）を選び、「再生」を押します。
- 断面図の右にある縦長の「押して吸う」を押している間だけ吸います。下ほど弱く（4 L/分）、上ほど強く（20 L/分）吸います。スペースキーでも吸えます。
- 「吸わずに5分進める」で蒸らしを早送りできます。「自動で吸う」は 2.6 秒・12 L/分の吸引を約 20 秒ごとに繰り返します。
- 吸っている間、気化した成分が色つきの粒子として気流に乗って流れます。色は成分表の丸と同じです。
- 効果音（水の泡と空気の音、過熱の警告音）は Web Audio で合成しています。

## 選べる条件

| 項目 | 選択肢 |
| --- | --- |
| ボウル | Cosmo Bowl Turkish / Cosmo Bowl Phunnel / Hype Bowl (Turkish) / Hype Killer Light / Thicc Bowl Killer |
| HMD | ONMO HMD / Na Grani V2 |
| 炭の配置 | 下2・上斜めがけ2 / 下2・上斜めがけ1 / 下2・上ピラミッド1 / 下1・上斜めがけ2 / 下2 |
| 炭のサイズ | 22 / 25 / 26 / 27 / 28 mm キューブ |
| フレーバー | Darkside Doppelgänger / Al Fakher Two Apples / Al Fakher Mint / Al Fakher Grape |

断面は下段の炭の列に直交する面です。下段2個は奥行き方向に並ぶため、断面には中央の1個分が写ります。

## 計算モデル

- 形状: ボウル・HMD・炭を 2 mm 格子の 3D で組み立てます。器具も炭の並びも中心の縦断面について対称なので、半分だけを計算します。薄い金属の壁は、セルを占める割合で熱容量と熱伝導を割り引いて表します。
- 熱: 熱伝導を陽解法で解きます。すき間をはさむ面どうしの放射は、各面から光線を飛ばして形態係数を求め、射度の式で解きます。外面からは外気へ対流・放射で逃げ、HMD の開口に続く空気は浮力で外気と入れ替わります。
- 炭: 塊ごとに芯の温度・質量・灰の殻の厚さを持ちます。燃える速さは、表面へ届く酸素の量で決まります。酸素は境膜・灰の殻・表面反応の3つの抵抗を直列に通ります。発熱は消費した酸素の量から求めます（Thornton 則、13.1 MJ/kg-O2）。燃えた分だけ芯が小さくなり、一部が灰の殻として残ります。殻が厚くなると酸素が届きにくくなって火力が落ち、熱も外へ出にくくなります。
- 気流: 開いた空間・穴あき金属・葉を通気抵抗の違う層とみなし、圧力場を共役勾配法で解きます。流量は吸う強さに比例させます。吸っている間は炭の表面の流れが速くなり、酸素が多く届きます。
- 気化: 通過する空気が各セルで気液平衡に近づくとして、水・グリセリン・香料・ニコチンを個別に追跡します。空気側の物質移動は熱移動と同じ速さとし（Chilton–Colburn）、シロップ側の拡散抵抗を直列に足します。水の活量は Norrish 式（グリセリン・糖による低下）で求めます。吸っていない間も、沸点を超えた分は沸騰し、葉の表面からも蒸発します。

## 途中の操作

- 灰を落とす: 灰の殻を 0.2 mm だけ残して取り除きます。酸素が届きやすくなり、火力と HMD の温度が戻ります。炭は小さくなったままです。
- 配置を変える: 「炭の配置」を途中で変えると、今ある炭の温度・大きさ・灰を引き継いで置き直します。足りない分は新しい炭を足し、余った分は外します。
- 上段と下段の炭を入れ替える / 新しい炭に替える。
- 温度の推移のグラフに、操作した時刻の印が付きます。

## 較正

公開されている実測例に合わせて、`js/sim.js` の `TUNE` を決めています。

- 吸うと上層の温度が下がり、吸い終わると戻る: Perraud ら 2019（ヘッド内で約 −50℃）、hookahpro.ru のフォーラムの熱電対計測（葉の中心で約 −10℃、10〜15 秒で戻る）、シシャニキ氏の note（上層で 60〜100℃ 下がる）。強制対流の係数 `hForced` は、相関式の値（23）では吸ったときに上層が温まってしまうため、実測の向きに合う 8 にしました。
- 灰を落とすと温度が戻る: hookahpro.ru（Lotus の表面が +5℃、吸い続けると元に戻る）。定量的な較正はしていません。
- 層ごとの温度: シナモン佐藤氏の note（Cosmo Bowl Turkish・ONMO・26 mm×4 個で、蒸らし 8 分後に上層 108℃・下層 52℃）。このモデルは蒸らし 8 分の上層を 150℃台と高めに出します。葉の水分量と HMD 床の温度の実測がなく、ここは合わせ切れていません。

## 限界

- 2 mm 格子なので、葉の層は 6〜8 セルの厚さしかありません。「上層」は表面から約 4 mm の平均で、表面直下に刺した熱電対より低めに出ます。
- 炭の状態は塊ごとに1つです。下段2個は対称の面をはさんで同じ状態として扱います。
- ボウルと HMD の形は公表寸法からパラメータで作図しています。公表値のない寸法は仮定で、画面下部の「根拠」に器具ごとに明記しています。
- フレーバーの配合は非公開です。香気成分の種類は文献と製品説明に基づき、量と活量係数は仮定です。
- 炭の密度・灰の体積・灰の熱伝導率と酸素の通りやすさは仮定です。

## 開発

```
npm test         # シミュレーションのテスト
npm run serve    # http://localhost:8080 で確認
node test/tune.mjs hForced=8 cosmoTurkish,onmo,l2   # 較正値を変えて試す
```

- `js/data.js` 器具・炭・フレーバー・物性
- `js/geometry.js` 3D 形状と炭の置き方
- `js/sim.js` 熱・炭の燃焼・気化の計算（較正値は `TUNE`）
- `js/flow.js` 気流（圧力場）
- `js/radiation.js` 面どうしの放射
- `js/render.js` 断面図・粒子・グラフ
- `js/view3d.js` 3D 表示（three.js を CDN から読み込む）
- `js/audio.js` 効果音
- `js/main.js` 画面操作
