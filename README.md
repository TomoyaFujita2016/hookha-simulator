# シーシャ熱・香りシミュレーター

ボウルと HMD の縦断面、炭の配置、吸う強さから、葉の上・中・下層の温度と、温度ごとに気化する香料・グリセリンを計算する静的サイトです。ビルド不要で、GitHub Pages（main ブランチのルート）でそのまま動きます。

## 使い方

- 条件（ボウル、HMD、炭の配置、炭のサイズ、フレーバー）を選び、「再生」を押します。
- 断面図の右にある縦長の「押して吸う」を押している間だけ吸います。下ほど弱く（4 L/分）、上ほど強く（20 L/分）吸います。スペースキーでも吸えます。
- 「吸わずに5分進める」で蒸らしを早送りできます。「自動で吸う」は 2.6 秒・12 L/分の吸引を約 20 秒ごとに繰り返します。
- 吸っている間、気化した成分が色つきの粒子として気流に乗って流れます。色は成分表の丸と同じです。
- 効果音（水の泡と空気の音、過熱の警告音）は Web Audio で合成しています。

## 選べる条件

| 項目 | 選択肢 |
| --- | --- |
| ボウル | Cosmo Bowl Turkish / Cosmo Bowl Phunnel / Hype Bowl (Turkish) / Hype Killer Light / Thicc Bowl Killer |
| HMD | ONMO HMD / Na Grani V2 |
| 炭の配置 | 下2・上斜めがけ2 / 下2・上斜めがけ1 / 下2・上ピラミッド1 / 下1・上斜めがけ2 / 下2 |
| 炭のサイズ | 22 / 25 / 26 / 27 / 28 mm キューブ |
| フレーバー | Darkside Doppelgänger / Al Fakher Two Apples / Al Fakher Mint / Al Fakher Grape |

断面は下段の炭の列に直交する面です。下段2個は奥行き方向に並ぶため、断面には中央の1個分が写ります。

## 計算モデル

- 熱: 1 mm 格子の縦断面で、熱伝導、すき間の放射（すき間幅に応じた等価熱伝導率）、外気への対流・放射、吸引時の空気による熱の運搬を陽解法で解きます。炭は発熱体で、温度は発熱と放熱の釣り合いで決まります。
- 気流: 葉を通気抵抗のある層とみなしたポテンシャル流れを形状ごとに解き、吸引流量に比例させます。
- 気化: 通過する空気が各セルで気液平衡に近づくとして、水・グリセリン・香料・ニコチンを個別に追跡します。蒸気圧は沸点と蒸発エンタルピーから Clausius-Clapeyron 式で求め、蒸発潜熱を葉の温度に反映します。冷えた下層では過飽和分の一部が再凝縮します。

## 限界

- 断面 2D の計算を円形の実物に換算した推定値で、実機の測定で検証したものではありません。較正は ONMO HMD に炭2〜3個を載せた条件が、公開されている実測例（上層約200℃）に近づくよう行いました。Na Grani や炭4個相当の条件は外挿で、温度を高めに見積もっている可能性があります。
- ボウルと HMD の形は公表寸法からパラメータで作図しています。公表値のない寸法は仮定で、画面下部の「根拠」に器具ごとに明記しています。Na Grani V2 と Thicc Bowl Killer は固有の寸法が見つからず、それぞれ Na Grani と THICC Bowl の公表寸法を使っています。
- フレーバーの配合は非公開です。香気成分の種類は文献と製品説明に基づき、量と活量係数は仮定です。

## 開発

```
npm test         # シミュレーションのテスト
npm run serve    # http://localhost:8080 で確認
node test/tune.mjs coalPower=6e6 cosmoTurkish,onmo,l2   # 較正値を変えて試す
```

- `js/data.js` 器具・炭・フレーバー・物性
- `js/geometry.js` 断面の組み立て
- `js/sim.js` 熱・気流・気化の計算（較正値は `TUNE`）
- `js/render.js` 断面図・粒子・グラフ
- `js/audio.js` 効果音
- `js/main.js` 画面操作
